# php-orders-processing

Консольный PHP-скрипт для обработки заказов из JSON.

## Требования

PHP 8.1 или выше.

## Запуск

```
php orders.php
```

Файл orders.json должен находиться в одной директории с orders.php.

## Пример результата

```
Количество оплаченных заказов: 3
Общая сумма оплаченных заказов: 4500
Самый дорогой оплаченный заказ: № 103 на сумму 3000

Количество заказов по статусам:
paid: 3
pending: 1
```
